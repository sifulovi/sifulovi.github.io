> **প্রেক্ষাপট:** নিচের সব প্রশ্ন একটা হাসপাতালের ডেটাবেজ নিয়ে। কল্পনা করুন আপনি একটা হাসপাতালের সফটওয়্যারে কাজ করছেন। সেখানে তিনটা প্রধান টেবিল আছে:
>
> | টেবিল | কী রাখে | গুরুত্বপূর্ণ কলাম |
> |---|---|---|
> | `patients` | রোগীদের তথ্য | `patient_id`, `first_name`, `last_name`, `birth_date`, `city`, `province_id`, `height`, `allergies` |
> | `admissions` | রোগী কবে ভর্তি হলো, কী রোগ ধরা পড়ল | `patient_id`, `admission_date`, `diagnosis` |
> | `doctors` | ডাক্তারদের তথ্য | `first_name`, `last_name` |
>
> প্রতিটা প্রশ্নে থাকবে — কী চাওয়া হয়েছে, বাস্তব উদাহরণ দিয়ে ব্যাখ্যা, এবং কোয়েরি।

## ১. রোগীদের জন্মসাল গুলো ইউনিকভাবে দেখান, ছোট থেকে বড় ক্রমে

**বাস্তব উদাহরণ:** হাসপাতালে ১০,০০০ রোগী আছে। অনেকেরই জন্মসাল একই — যেমন ১৯৯০ সালে জন্ম নেওয়া ২০০ জন রোগী আছে। আপনি জানতে চান "মোট কত রকমের জন্মসাল আমাদের ডেটাবেজে আছে?" তখন `DISTINCT` লাগবে, যেটা ডুপ্লিকেট বাদ দিয়ে দেয়।

```sql
SELECT DISTINCT YEAR(birth_date)
FROM patients
ORDER BY YEAR(birth_date) ASC;
```

**মনে রাখুন:** `YEAR()` ফাংশন একটা পুরো তারিখ (যেমন `1990-05-12`) থেকে শুধু সালটা (`1990`) বের করে আনে।

## ২. যেসব `first_name` পুরো লিস্টে মাত্র একবার আছে, সেগুলো দেখান

**বাস্তব উদাহরণ:** ক্লাসে রোল কল করার সময় "রহিম" নামে ৫ জন থাকলে ঝামেলা হয়। আপনি জানতে চান — কোন নামগুলো একদমই ইউনিক, মানে ঐ নামে হাসপাতালে মাত্র একজনই রোগী আছে।

```sql
SELECT first_name
FROM patients
GROUP BY first_name
HAVING COUNT(first_name) = 1;
```

**`WHERE` আর `HAVING`-এর পার্থক্য (জুনিয়রদের সবচেয়ে বড় কনফিউশন):**
- `WHERE` কাজ করে **গ্রুপ করার আগে**, প্রতিটা রো-এর উপর।
- `HAVING` কাজ করে **গ্রুপ করার পরে**, প্রতিটা গ্রুপের উপর।
- এখানে "কতবার এসেছে" জানতে হলে আগে গ্রুপ করতে হবে, তাই `HAVING` লাগছে।

## ৩. যাদের নাম `s` দিয়ে শুরু ও `s` দিয়ে শেষ এবং কমপক্ষে ৬ অক্ষরের

**বাস্তব উদাহরণ:** ধরুন "Sagars", "Sameds", "Sofias" — এরকম নাম খুঁজছেন। কিন্তু "Sos" (৩ অক্ষর) বাদ যাবে, কারণ কমপক্ষে ৬ অক্ষর লাগবে।

```sql
SELECT patient_id, first_name
FROM patients
WHERE first_name LIKE 's%____%s';
```

**প্যাটার্নটা ভেঙে দেখুন:**
- `s` → শুরুতে s
- `%` → যেকোনো সংখ্যক অক্ষর (০ বা তার বেশি)
- `____` → ঠিক ৪টা অক্ষর (প্রতিটা `_` মানে ঠিক ১টা অক্ষর)
- `%` → আবার যেকোনো সংখ্যক অক্ষর
- `s` → শেষে s

সব মিলিয়ে: প্রথম `s` + ৪টা অক্ষর + শেষ `s` = কমপক্ষে ৬ অক্ষর। ✅

## ৪. যাদের রোগ নির্ণয় হয়েছে `Dementia`, তাদের `patient_id`, `first_name`, `last_name`

**বাস্তব উদাহরণ:** ডিমেনশিয়া (স্মৃতিভ্রংশ) রোগীদের জন্য আলাদা কেয়ার ইউনিট বানাতে হবে। কিন্তু রোগের তথ্য আছে `admissions` টেবিলে, আর নাম আছে `patients` টেবিলে। তাই দুই টেবিল **জোড়া (JOIN)** লাগাতে হবে — `patient_id` দিয়ে।

```sql
SELECT p.patient_id, p.first_name, p.last_name
FROM patients p
LEFT JOIN admissions a ON p.patient_id = a.patient_id
WHERE a.diagnosis = 'Dementia';
```

**JOIN-কে সহজভাবে বুঝুন:** দুইটা এক্সেল শিট আছে। এক শিটে রোল নম্বর + নাম, আরেক শিটে রোল নম্বর + পরীক্ষার নম্বর। রোল নম্বর মিলিয়ে দুইটা শিট পাশাপাশি জোড়া লাগানোই হলো JOIN।

## ৫. প্রতিটা রোগীর নাম দেখান — নামের দৈর্ঘ্য অনুযায়ী, তারপর বর্ণানুক্রমে

**বাস্তব উদাহরণ:** আইডি কার্ড প্রিন্ট করবেন, ছোট নাম আগে ছাপালে কাগজ বাঁচে। একই দৈর্ঘ্যের নাম হলে A-Z ক্রমে সাজান।

```sql
SELECT first_name
FROM patients
ORDER BY LENGTH(first_name), first_name;
```

`ORDER BY`-তে কমা দিয়ে একাধিক কলাম দিলে — প্রথমটা দিয়ে সাজায়, প্রথমটা সমান হলে দ্বিতীয়টা দিয়ে টাই-ব্রেক করে।

## ৬. যাদের `Penicillin` বা `Morphine`-এ অ্যালার্জি আছে

**বাস্তব উদাহরণ:** নার্সকে একটা তালিকা দিতে হবে — "এই রোগীদের ভুলেও পেনিসিলিন বা মরফিন দেবেন না।" ভুল হলে রোগীর জীবন সংশয় হতে পারে।

```sql
SELECT first_name, last_name, allergies
FROM patients
WHERE allergies IN ('Penicillin', 'Morphine')
ORDER BY allergies, first_name, last_name;
```

**`IN` কেন ব্যবহার করবেন:** `WHERE allergies = 'Penicillin' OR allergies = 'Morphine'` লিখলেও একই ফল হতো। কিন্তু ১০টা ওষুধের নাম হলে `IN` অনেক পরিষ্কার ও ছোট।

## ৭. যারা একই রোগ নিয়ে একাধিকবার ভর্তি হয়েছে

**বাস্তব উদাহরণ:** একজন রোগী যদি বারবার একই রোগ নিয়ে ফিরে আসে, তার মানে চিকিৎসাটা ঠিকমতো কাজ করছে না। হাসপাতালের কোয়ালিটি টিম এটা মনিটর করে।

```sql
SELECT DISTINCT a1.patient_id, a1.diagnosis
FROM admissions a1
WHERE 1 < (
    SELECT COUNT(*)
    FROM admissions a2
    WHERE a1.patient_id = a2.patient_id
      AND a1.diagnosis = a2.diagnosis
);
```

**কীভাবে কাজ করছে:** প্রতিটা রো (`a1`)-এর জন্য ভেতরের কোয়েরি গুনে দেখছে — "এই রোগীর, এই রোগের এন্ট্রি মোট কয়টা?" যদি ১-এর বেশি হয়, তার মানে সে একাধিকবার এসেছে।

**সহজ বিকল্প (একই ফল, পড়তে সহজ):**
```sql
SELECT patient_id, diagnosis
FROM admissions
GROUP BY patient_id, diagnosis
HAVING COUNT(*) > 1;
```

## ৮. প্রতিটা শহরে কতজন রোগী — বেশি থেকে কম ক্রমে

**বাস্তব উদাহরণ:** কোন শহরে সবচেয়ে বেশি রোগী, সেখানে নতুন ব্রাঞ্চ খোলার সিদ্ধান্ত নিতে এই তথ্য লাগবে।

```sql
SELECT city, COUNT(patient_id) AS total_patients
FROM patients
GROUP BY city
ORDER BY total_patients DESC, city ASC;
```

## ৯. রোগী ও ডাক্তার — সবার নাম এক তালিকায়, ভূমিকা সহ

**বাস্তব উদাহরণ:** হাসপাতালের গেটে একটা এন্ট্রি রেজিস্টার। সেখানে রোগী-ডাক্তার সবার নাম থাকবে, পাশে লেখা থাকবে সে কে।

```sql
SELECT first_name, last_name, 'Patient' AS role FROM patients
UNION ALL
SELECT first_name, last_name, 'Doctor'  AS role FROM doctors;
```

**`UNION` vs `UNION ALL`:**
- `UNION` → দুই তালিকা জোড়া লাগায় **এবং ডুপ্লিকেট বাদ দেয়** (ধীর, কারণ চেক করতে হয়)।
- `UNION ALL` → শুধু জোড়া লাগায়, ডুপ্লিকেট রেখে দেয় (দ্রুত)।
- এখানে একজন ডাক্তার আর একজন রোগীর নাম একই হলেও দুজনকেই দেখাতে হবে, তাই `UNION ALL`।

## ১০. সব অ্যালার্জি জনপ্রিয়তা অনুযায়ী দেখান, `NULL` বাদ দিয়ে

**বাস্তব উদাহরণ:** ফার্মেসিতে কোন ওষুধের বিকল্প বেশি স্টক রাখতে হবে সেটা ঠিক করতে — কোন অ্যালার্জি সবচেয়ে কমন সেটা জানা দরকার।

```sql
SELECT allergies, COUNT(*) AS cnt
FROM patients
WHERE allergies IS NOT NULL
GROUP BY allergies
ORDER BY cnt DESC;
```

**⚠️ খুব গুরুত্বপূর্ণ ভুল:** `WHERE allergies NOT NULL` লেখা যায় না। সঠিক লেখা `IS NOT NULL`। কারণ SQL-এ `NULL` মানে "মান নেই / অজানা", আর অজানার সাথে `=` বা `!=` দিয়ে তুলনা করা যায় না — সবসময় `IS NULL` / `IS NOT NULL` ব্যবহার করতে হয়।

## ১১. যাদের জন্ম ১৯৭০-এর দশকে

**বাস্তব উদাহরণ:** ৫০+ বয়সীদের জন্য ফ্রি হেলথ ক্যাম্প হবে। ১৯৭০ থেকে ১৯৭৯ সালে জন্ম নেওয়াদের খুঁজে বের করতে হবে।

```sql
SELECT first_name, last_name, birth_date
FROM patients
WHERE YEAR(birth_date) BETWEEN 1970 AND 1979
ORDER BY birth_date;
```

`BETWEEN 1970 AND 1979` মানে ১৯৭০ ও ১৯৭৯ **দুটোই ধরা হবে** (inclusive)।

## ১২. পুরো নাম এক কলামে — `LAST_NAME,first_name` ফরম্যাটে

**বাস্তব উদাহরণ:** সরকারি রিপোর্টে নাম লিখতে হয় "পদবি আগে, নাম পরে" ফরম্যাটে — যেমন `RAHMAN,karim`।

```sql
SELECT CONCAT(UPPER(last_name), ',', LOWER(first_name)) AS full_name
FROM patients
ORDER BY first_name DESC;
```

- `UPPER()` → সব বড় হাতের অক্ষর
- `LOWER()` → সব ছোট হাতের অক্ষর
- `CONCAT()` → কয়েকটা টেক্সট জোড়া লাগায়

## ১৩. যেসব প্রদেশে রোগীদের মোট উচ্চতার যোগফল ৭,০০০-এর বেশি

**বাস্তব উদাহরণ:** এটা একটু অদ্ভুত প্রশ্ন, কিন্তু আসল শিক্ষাটা হলো — গ্রুপ করার পর যোগফলের উপর শর্ত দেওয়া।

```sql
SELECT province_id, SUM(height) AS sum_height
FROM patients
GROUP BY province_id
HAVING SUM(height) >= 7000;
```

**⚠️ খেয়াল করুন:** প্রশ্নে বলা আছে "৭,০০০ বা তার বেশি", তাই `>=` হবে, শুধু `>` নয়।

## ১৪. মাসের কোন তারিখে সবচেয়ে বেশি রোগী ভর্তি হয়

**বাস্তব উদাহরণ:** যদি দেখা যায় মাসের ১ তারিখে সবচেয়ে বেশি ভর্তি হয় (বেতন পাওয়ার পর মানুষ ডাক্তার দেখায়), তাহলে ঐ দিন বেশি নার্স ডিউটিতে রাখতে হবে।

```sql
SELECT DAY(admission_date) AS day_number,
       COUNT(*)            AS number_of_admissions
FROM admissions
GROUP BY DAY(admission_date)
ORDER BY number_of_admissions DESC;
```

## ১৫. `patient_id` ৫৪২-এর সর্বশেষ ভর্তির সব তথ্য

**বাস্তব উদাহরণ:** একজন রোগী আজ এসেছে। ডাক্তার জানতে চান — "শেষবার কবে এসেছিল, কী সমস্যা ছিল?" পুরনো সব রেকর্ড নয়, শুধু সর্বশেষটা দরকার।

```sql
SELECT *
FROM admissions
WHERE patient_id = 542
ORDER BY admission_date DESC
LIMIT 1;
```

**প্যাটার্নটা মনে রাখুন:** "সর্বশেষ / সবচেয়ে বড় / টপ ১" চাইলে — `ORDER BY ... DESC` করে `LIMIT 1`।

## 📌 দ্রুত রিভিশন চিট-শিট

| যা করতে চান | যা ব্যবহার করবেন |
|---|---|
| ডুপ্লিকেট বাদ দিতে | `DISTINCT` |
| রো-লেভেলে ফিল্টার | `WHERE` |
| গ্রুপ করার পর ফিল্টার | `HAVING` |
| একাধিক মানের যেকোনো একটা মিললে | `IN (...)` |
| রেঞ্জের মধ্যে | `BETWEEN a AND b` |
| টেক্সট প্যাটার্ন মেলাতে | `LIKE` (`%` = যেকোনো, `_` = ঠিক ১টা) |
| খালি মান চেক | `IS NULL` / `IS NOT NULL` |
| দুই টেবিল জোড়া | `JOIN ... ON` |
| দুই ফলাফল উপর-নিচে জোড়া | `UNION ALL` |
| সর্বশেষ/টপ ১ | `ORDER BY ... DESC LIMIT 1` |

**SQL কোয়েরি আসলে যে ক্রমে চলে** (লেখার ক্রম নয়!):
`FROM` → `JOIN` → `WHERE` → `GROUP BY` → `HAVING` → `SELECT` → `ORDER BY` → `LIMIT`

এই ক্রমটা মনে রাখলে বোঝা যায় কেন `WHERE`-এ কলাম alias ব্যবহার করা যায় না, কিন্তু `ORDER BY`-তে যায় — কারণ `SELECT` চলার আগেই `WHERE` চলে যায়, তখনো alias তৈরিই হয়নি!
